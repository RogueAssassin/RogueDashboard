# Rogue product branding

Rogue Dashboard and RogueForge share one visual family while keeping distinct product marks.

## Shared language

- Midnight base: `#080b12`
- Violet primary: `#7c5cff`
- Cyan secondary: `#00e5ff`
- High-contrast near-white text: `#f5f7fb`
- Glass surfaces, soft neon edges and rounded geometric marks

## Rogue Dashboard

Use the **RD** container-orbit mark for the dashboard/monitoring product.

Assets:

- `docs/assets/rogue-dashboard-logo.svg` — full product lockup
- `app/static/favicon.svg` — compact product icon
- `docs/assets/hero.svg` — GitHub hero/banner

## RogueForge

Use the **RF** forge/hex mark for the stack-management companion. It deliberately uses the same palette and geometry so users recognise it as part of the Rogue ecosystem while the angular forge motif distinguishes privileged management from Dashboard visibility.

Assets:

- `docs/assets/rogueforge-logo.svg` — companion product lockup
- `docs/assets/rogue-ecosystem.svg` — side-by-side relationship graphic

## Usage

Keep clear space around each mark, avoid recolouring individual parts outside the shared palette, and do not use Docker or Podman trademarks as the primary product mark. Engine logos may be used separately to indicate compatibility.
